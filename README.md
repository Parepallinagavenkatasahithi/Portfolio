## ⚡ Live Portfolio Overview

A bespoke, editorial, modern personal portfolio website built with **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**. Designed with an ivory/deep-black aesthetic, subtle earthy green accents, generous whitespace, and an emphasis on first-principles engineering builds.

### Featured Projects Highlighted:

- **AI-PriceOptima**: Machine-learning-based dynamic pricing engine and demand elasticity simulator.
- **Hybrid Quantum Portfolio Optimization**: QAOA & variational quantum circuit optimization for discrete financial asset allocation.
- **30+ Technical Projects Catalog**: Archive of implementations across AI/ML, Quantum Algorithms, Full-Stack Software, and Data Science.

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```
